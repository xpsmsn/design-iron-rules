# 族 8 · 品牌驱动派

**核心逻辑**：品牌符号优先于功能表达。
**气质**：强记忆点、可传播、有主张。
**密度**：疏。

## 共同宪法

### 必须

- 有一个明确的核心符号：字、图形、形象、或动效，四选一为主
- 符号在首屏和静态缩略图状态下即可辨识（去掉动效也能认出）
- 核心信息不依赖装饰传达——去掉所有装饰，界面仍然可用
- 符号具备可复用性：能拆成图标、能做成 favicon

### 禁止

- 风格元素覆盖信息可读性
- 符号过多导致识别焦点分散
- 只有装饰没有内容（大色块 + 大字体 + 无信息）

## 8.1 大字排版 Big Type

### 气质
文字即主视觉。字重、字距、字号承担全部视觉重量，无图片或极少图片。

### 构成要点

- **极大字**：标题 96–200px，占据首屏主要面积
- **强对比**：超大字（200px）+ 小正文（16px），字号比可达 12:1
- **字重对比**：细体大字 + 粗体小字，或反之
- **紧排**：大字用负字距 `-0.04em`，中文用紧排更紧凑
- **字体即品牌**：定制或选用特征明显的字体
- **布局**：非对称，文字块大小对比强烈
- **色彩**：文字本身就是主视觉，可用彩色文字 + 极简背景
- **动效**：文字逐行/逐字入场

### 必须

- 大字承担标题与展示性文本，**功能性文本（表单标签、按钮、导航、数据）保持正常字号**
- 可读性下限：大字也不能用低对比配色
- 换行位置手动控制，避免在词组中间断开

### 禁止

- 全站所有文字都用超大字（功能界面会不可用）
- 超大字使用超紧字距导致字符粘连
- 用超大字承载需要快速扫视的信息（用户要读的不是读）

### 翻车点

- 不可用：好看但信息全在大字里，功能部分完全缺失
- 中文字体的超大字排版问题：中文没有天然的英文那种紧排效果，字距设负会粘连
- 首屏好看但内页崩塌（设计只在封面做足）
- 「字大就是设计」的误解，缺少字体选择与排版节奏的设计

## 8.2 3D 插画与吉祥物 3D & Mascot

### 气质
3D 形象承担品牌表达。人格化角色引导用户。

### 构成要点

- **3D 渲染**：柔和工作室光照、次表面散射、哑光材质（有质感但不高光）
- **吉祥物**：人格化角色，在空态、加载态、引导流程中出现
- **场景一致性**：3D 形象的环境光与 UI 主色一致
- **多状态**：同一形象表达多种状态（空态/加载/成功/错误），角色情绪与状态对应
- **辅助功能**：3D 形象旁必须有文字说明，形象不能是唯一信息来源

### 必须

- 3D 形象不遮挡任何信息，位置固定（通常在空态或引导角落）
- 提供静态降级（低性能设备用 PNG/静态图）
- 空态有 3D 形象时，必须同时有「为什么空 + 下一步动作」
- 形象的情绪与场景匹配（错误态不能配微笑角色）

### 禁止

- 加载态用无限循环的 3D 动画（消耗性能且不传达进度）
- 3D 形象作为唯一的状态指示（无障碍失败）
- 吉祥物遮挡表单或按钮
- 每个页面放不同的 3D 形象，角色一致性崩溃

### 翻车点

- 3D 资源体积大（单个模型 2–10MB），首屏加载慢
- 风格与 UI 不统一：3D 渲染精致但 UI 扁平，反差突兀
- 吉祥物喧宾夺主：用户注意力在角色上，不在操作上
- 错误态配错误的表情/语气（这在用户投诉里是高频问题）

## 8.3 品牌动效 Brand Motion

### 气质
动效本身是品牌资产。签名式的标志动效、微交互驱动的识别度。

### 构成要点

- **标志动效**：Logo 有自己的动画（变形、绘线、呼吸），且短于 1s
- **动态色**：品牌主色随场景/内容/状态变化，仍在色域约束内
- **微交互签名**：某个交互有独特的动效语言（如按钮按下时的形变而非变色）
- **转场语言**：页面转场有统一的空间逻辑（从哪来到哪去）
- **节奏**：动效有统一的缓动曲线（全局只用 2–3 条曲线）

### 必须

- 全局缓动曲线 ≤ 3 条，明确定义（进入/退出/强调），不做逐个组件自定义
- 动效服务信息理解（说明来源去向），不只是装饰
- 完整实现 `prefers-reduced-motion` 降级
- 动效不阻塞操作：加载动画不能阻止用户离开

### 禁止

- 动效超过 400ms（页面转场）或 800ms（品牌动画）
- 循环动效无常驻停止条件
- 为了动效牺牲首屏性能（动画资源 > 200KB 或主线程长任务 > 50ms）
- 每个组件有独立的动效逻辑

### 翻车点

- 动效分散：每个页面的转场逻辑不同，用户失去空间感
- 首屏性能受损：为了品牌动效牺牲可交互时间
- 忽略 `prefers-reduced-motion`：前庭功能障碍用户会因此无法使用产品（这也是无障碍违规）
- 动效与反馈混淆：装饰动画被误认为加载反馈，用户不知道系统在干什么
- 品牌动效过度堆叠（Logo 动效 + 页面转场 + 按钮形变 + 光标效果），视觉疲劳
