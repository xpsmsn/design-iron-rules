# Token · 排版与间距

## 间距 scale（4px 基线）

```
--space-1:  4px
--space-2:  8px
--space-3:  12px
--space-4:  16px
--space-5:  20px
--space-6:  24px
--space-8:  32px
--space-10: 40px
--space-12: 48px
--space-16: 64px
--space-20: 80px
--space-24: 96px
```

### 风格覆写

| 风格 | 覆写 |
|---|---|
| 1.4 专业高密度 | 额外加入 `--space-1.5: 6px`；正文相关间距整体降一档 |
| 1.1 瑞士极简 | 间距档位只用 `8/16/32/64/96/128`，跳档使用 |
| 2.2 Material You | 增加 `--space-7: 28px`、`--space-14: 56px`（Material 8pt 栅格含半档） |
| 8.1 大字排版 | 大标题上下间距 ≥ `--space-16`，常配 `--space-24` |

### 亲密性原则

同组元素间距 < 异组元素间距。经验值：

- 图标与文字：4–8px
- 标签与输入框：8px
- 表单字段之间：16–24px
- 区块之间：32–48px
- 页面区块之间：64–96px

## 字号 scale

```
--text-xs:   12px   角标、辅助标签（仅短文本，不承载信息）
--text-sm:   13px   密集界面正文
--text-base: 15px   默认正文下限
--text-md:   16px   标准正文
--text-lg:   18px   导语、次级标题
--text-xl:   20px   卡片标题
--text-2xl:  24px   区块标题
--text-3xl:  30px   页面标题
--text-4xl:  36px   大标题
--text-5xl:  48px   展示标题
--text-6xl:  64px   巨标题
--text-7xl:  96px   巨幅标题 / 8.1 大字排版
--text-8xl:  144px  8.1 大字排版上限
```

### 约束

- 正文不得低于 `--text-base`（15px）；高密度场景最低 `--text-sm`（13px），且仅限数字与短标签
- 一个视图内字号档位 ≤ 6
- 相邻两级标题字号比 ≥ 1.2，否则层级不成立
- 中文正文建议 15–17px，比西文大 1–2px 方块字更易读

## 行高

| 类型 | 值 |
|---|---|
| 中文正文 | 1.6–1.8 |
| 西文正文 | 1.5–1.7 |
| 紧凑表格 | 1.4–1.5 |
| 多行输入框 | 1.5 |
| 标题（≤ 30px） | 1.3–1.4 |
| 标题（> 30px） | 1.1–1.2 |
| 巨幅标题（> 96px） | 1.0–1.05 |

## 字重

```
--font-regular:  400
--font-medium:   500
--font-bold:     700
```

- 字重档位 ≤ 3
- 层级优先靠字号 + 颜色明度差，其次才是字重
- 中文不宜用 300 以下字重（细笔画在屏幕上会消失）

## 字距

| 场景 | letter-spacing |
|---|---|
| 巨幅标题（> 96px） | `-0.04em` |
| 大标题（48–96px） | `-0.03em` |
| 中文标题（24–48px） | `-0.02em` |
| 正文 | `0` |
| 全大写英文标签 | `+0.06em ~ +0.1em` |
| 小字号中文（≤ 13px） | `0`（不收紧） |

中文正文**永远不要用负字距**。

## 圆角

```
--radius-none:  0px
--radius-sm:    4px    输入框、按钮（瑞士/秩序派）
--radius-md:    8px    按钮、输入框（通用默认）
--radius-lg:    12px   卡片
--radius-xl:    16px   大卡片、弹层
--radius-2xl:   24px   族 3 黏土 / 2.2 Material
--radius-full:  9999px 胶囊、头像、开关
```

### 风格覆写

| 风格 | 圆角 |
|---|---|
| 6.1 粗野主义 | 0（或全 2px） |
| 1.1 / 1.2 秩序派 | 0–8px |
| 2.2 Material You | 按钮 full，卡片 16–28px |
| 3.2 黏土风 | 24–32px，图标容器 full |
| 族 5 TUI | 0 |

### 嵌套规则

内层圆角 = 外层圆角 − 内边距。内层圆角不能大于外层，否则视觉上会"顶出来"。

一个视图内圆角档位 ≤ 3。

## 阴影

```
--shadow-0: none
--shadow-1: 0 1px 2px rgba(0,0,0,.06), 0 1px 3px rgba(0,0,0,.10)
--shadow-2: 0 4px 12px rgba(0,0,0,.08)
--shadow-3: 0 12px 32px rgba(0,0,0,.12)
--shadow-4: 0 24px 64px rgba(0,0,0,.16)
```

### 规则

- 阴影色带品牌色相偏移（例：`rgba(30,40,80,.08)` 蓝调黑），纯黑阴影在暖色界面上显脏
- 暗色模式阴影加强为 `rgba(0,0,0,.5+)` 并同时补 1px 边框
- 族 1（秩序派）默认零阴影，用边框替代
- 族 6 硬阴影 `4px 4px 0 #000`，零模糊
- 族 3 阴影浅而大，偏移与模糊比例不同于族 1

## 栅格

```
--grid-columns: 12
--gutter:        24px      （移动端 16px）
--page-padding:  16px / 24px / 32px   （移动 / 平板 / 桌面）
--content-max:   1280px    （内容型 720px）
--reading-max:   680–760px （正文限宽）
```

断点：`360 · 768 · 1024 · 1440 · 1920`

## Z 轴

```
--z-base:       0
--z-content:    10
--z-sticky:     400
--z-floating:   300
--z-modal:      1000
--z-toast:      2000
--z-tooltip:    2100
```

吸顶元素必须处理下方内容滚上来的情况：加毛玻璃 + 边框，或加渐变遮罩。

## 布局尺寸上限

| 元素 | 建议值 |
|---|---|
| 正文阅读宽 | 680–760px |
| 表单字段宽 | 320–480px |
| 单栏内容宽 | 720–880px |
| 按钮（主） | 最小 96px，推荐 120–160px |
| 按钮（次） | 最小 64px |
| 输入框高 | 40–48px |
| 触摸热区 | 44–48px |
| 头像 | 32 / 40 / 48 / 64 / 96 |
| 图标 | 12 / 16 / 20 / 24 / 32 |
