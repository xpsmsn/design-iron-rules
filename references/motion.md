# 动效定律

动效的判断标准只有一条：**它是否帮助用户理解发生了什么。** 不满足就删掉。

## 时长

```
--dur-instant:  80ms     按压反馈
--dur-fast:     120ms    hover、小元素状态变化
--dur-base:     200ms    常规元素进出、展开折叠
--dur-slow:     300ms    弹层出现、抽屉
--dur-page:     400ms    页面转场（上限）
--dur-brand:    800ms    品牌动画（仅标志/主视觉，且不可交互前不阻塞）
```

### 这些是默认值，不是普适真理

时长取决于**位移距离、动效复杂度、平台性能、用户所处情境**。规则是：

- 位移越远 → 时长越长；位移 4px 和位移 40px 不该用同一个值
- 出场比入场**快 30%**（入场有内容需要看清，出场只需表达"走了"）
- 400ms 是**阻塞性动效**的上限。非阻塞的装饰动画可以更长，但必须能随时被打断
- 超过 1s 且不可跳过的等待必须提供进度或可离开路径

不要把某一个区间（如 150–300ms）当成放之四海皆准的要求去套所有场景。

### 动效预设目录

已备 22 条预设，含强度分级与具体「忌」，避免凭感觉定时长：

```bash
node scripts/catalog.js motion "悬停"     # 按触发场景检索
```

强度分三档：

| 强度 | 适用 | 特征 |
|---|---|---|
| Subtle | 功能性反馈、列表入场 | 位移 ≤ 8px，纯淡入或轻微位移，几乎无存在感 |
| Standard | 常规交互动效 | 位移 8–24px，时长 150–300ms |
| Complex | 品牌表达、叙事滚动 | 位移 > 24px，可含遮罩与视差，**单屏 ≤ 2 处** |

## 缓动（全局 ≤ 3 条）

```
--ease-out:    cubic-bezier(0.0, 0.0, 0.2, 1)        元素进入、展开（默认）
--ease-in:     cubic-bezier(0.4, 0.0, 1, 1)          元素退出
--ease-in-out: cubic-bezier(0.4, 0.0, 0.2, 1)       位置移动、页面转场
--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1)     回弹（仅族 3 / 8.3 允许）
```

- 缓动函数不得逐组件自定义，破坏全局运动语言
- 位移一律用 `ease-out`（物体进入视野时减速更自然）
- 颜色/透明度变化用 `ease-in-out`（无空间感）
- 回弹曲线禁止用于功能性元素（会显得弹、延迟精确操作）

## 空间一致性

- 进入 = 从位移来源方向进入；退出 = 向来源方向退出
- 层级越高的元素移动距离越远（弹层 24–32px，浮层 12–16px，元素 4–8px）
- 相关元素成组一起动，不要单独飞入

## 加载动效

| 时长 | 处理 |
|---|---|
| < 300ms | 不显示加载指示（闪一下更干扰） |
| 300ms – 1s | 旋转指示器或文字「加载中」 |
| 1s – 3s | 骨架屏（结构已知时最佳） |
| > 3s | 进度条 + 说明文字 + 可取消 |

- 骨架屏形状必须与真实内容结构一致，否则内容出现时会跳版
- 加载指示器不用整屏旋转图标（大面积旋转会吸引全部注意力）
- 禁止用动效掩盖长时间无响应

## 微交互

- 按下反馈 80ms 内出现
- 提交按钮：点击后立即进入 loading + 禁用，直到返回明确结果
- 开关类：滑块 + 轨道底色双通道表达状态，不靠位移单独表达
- 长列表：滚动时吸顶元素进入用 200ms，避免每次滚动都触发

## 页面转场

- 必须有空间逻辑：前进时新页面从右侧进、后退时从左侧进（移动端）；层级下钻用缩放 + 淡入
- 转场期间旧页面不卸载到造成闪白
- 提供返回路径，转场不能是"单向门"
- **不做全屏花哨转场**（3D 翻转、粒子）：一次两次是彩蛋，每次都是干扰

## 循环动效

| 类型 | 上限 |
|---|---|
| 呼吸/脉冲（提示用） | 有停止条件，不超过 3 个 |
| 背景装饰漂移 | 周期 ≥ 15s，位移幅度小 |
| 加载指示 | 正常 |
| 悬停跟随 | 指针停止后 300ms 内停止 |

循环动效必须全部响应 `prefers-reduced-motion`。

## `prefers-reduced-motion` 降级

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: .01ms !important;
    scroll-behavior: auto !important;
  }
}
```

降级不是"什么都不动"，而是**换成不引发前庭不适的等价表达**：

- 位移 → 透明度切换
- 缩放 → 透明度切换
- 视差、旋转、缩放循环动画 → 完全移除
- 自动轮播 → 停止自动播放，改为手动
- 平滑滚动 → 瞬时跳转

前庭功能障碍用户会因为大幅位移、视差、旋转动画产生真实的眩晕与头痛。这不是偏好问题，是无障碍问题。

## 性能

- 合成器友好：只用 `transform` 与 `opacity`，避免动画 `width/height/top/left`
- `will-change` 谨慎使用，用完移除（长期占用显存）
- 单个动画元素 `filter: blur()` + `backdrop-filter` 同屏 ≤ 3
- 主线程长任务 < 50ms；品牌动效不阻塞首次可交互时间（LCP / TTI 不受影响）
- 60fps 预算内最多同时运行 3 个持续动画

## 反模式

- 动效时长不统一：同一个交互在 A 页 200ms、B 页 400ms
- 元素从屏幕外飞入，用户需要等它飞完才能操作
- 循环动画无停止条件
- 入场动画遮挡首屏内容，拖慢 LCP
- 装饰动画被误认为加载反馈
- 用动效掩盖性能问题（本来该是骨架屏的地方放了加载动画）
- `prefers-reduced-motion` 缺失
