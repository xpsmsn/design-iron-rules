# 风格谱系 · 8 族 25 式

## 为什么按渲染逻辑分族

按「长得像不像」分类会互相打架：玻璃拟态和孟菲斯撞色是两个极端，却都被归进「现代风」；新拟态和写实拟物都算拟物，却完全不能共存。

按**渲染方式**分族后，同族内部可自由混搭，跨族才需要判断取舍。

| 族 | 渲染逻辑 | 核心手段 | 视觉信号 |
|---|---|---|---|
| 1 秩序理性 | 网格与排版驱动一切 | 严格栅格、大留白、字号层级 | 对齐、留白、克制 |
| 2 扁平几何 | 纯色块与几何形状 | 无渐变无阴影、鲜明色块 | 色块、圆角方、图标 |
| 3 触感拟物 | 阴影模拟真实体积 | 同色系双向阴影、材质纹理 | 凸起、凹陷、软 |
| 4 光学透明 | 模糊与透光 | 背景模糊、半透明、光晕 | 玻璃、折射、辉光 |
| 5 未来复古 | 时代符号叠加 | 霓虹、像素、等宽字、故障 | 扫描线、噪点、辉光 |
| 6 粗野原始 | 暴露结构本身 | 硬边框、粗线、原始色块 | 网格线、错位、贴纸 |
| 7 文化地域 | 传统材质与纹样 | 宣纸纹、印泥、格栅、朱红 | 材质肌理、印章、留白 |
| 8 品牌驱动 | 品牌符号优先 | 超大字、3D 形象、动态标识 | 强识别图形、大色块 |

## 25 式清单

### 族 1 · 秩序理性派
适用：几乎所有正式产品的**基底**。密度决定具体风格。

| 风格 | 特征 | 适用 |
|---|---|---|
| [1.1 瑞士极简](style-01-order.md) | 无衬线、大留白、无阴影、强网格 | 品牌官网、作品集、SaaS 落地页 |
| [1.2 编辑杂志](style-01-order.md) | 衬线大标题、多栏、强对比字号跳跃 | 内容站、专题、长文阅读 |
| [1.3 暗黑优先](style-01-order.md) | 深底、高对比、发光强调色 | 开发者工具、影像/影音、夜间场景 |
| [1.4 专业高密度](style-01-order.md) | 紧凑行高、表格优先、多栏布局 | 交易终端、监控台、后台、IDE |

### 族 2 · 扁平几何派
适用：信息密度中等、需要清晰分区的通用产品。

| 风格 | 特征 | 适用 |
|---|---|---|
| [2.1 经典扁平](style-02-flat-geometric.md) | 纯色、无阴影、无渐变 | 通用 SaaS、表单、工具类 |
| [2.2 Material You](style-02-flat-geometric.md) | 动态取色、圆润容器、动态色 | 消费级 App、安卓体系、教育产品 |
| [2.3 孟菲斯撞色](style-02-flat-geometric.md) | 高饱和撞色、手绘几何、Y2K | 活动页、儿童/青少年、社区 |

### 族 3 · 触感拟物派
适用：需要物理隐喻降低理解成本，或追求柔和亲和。

| 风格 | 特征 | 适用 |
|---|---|---|
| [3.1 新拟态](style-03-tactile-material.md) | 同色系双向阴影、凸起凹陷 | 音乐播放、极简开关、智能家居 |
| [3.2 黏土风](style-03-tactile-material.md) | 3D 黏土质感、超大圆角、软阴影 | 教育、儿童、社交、轻量工具 |
| [3.3 写实拟物](style-03-tactile-material.md) | 真实材质、光影、纹理 | 音乐/影像专业软件、游戏 |
| [3.4 有机自然](style-03-tactile-material.md) | 不规则形状、暖色、叶片肌理 | 环保、健康、农业、生活方式 |

### 族 4 · 光学透明派
适用：需要层级穿透感、悬浮导航、或强氛围的产品。

| 风格 | 特征 | 适用 |
|---|---|---|
| [4.1 玻璃拟态](style-04-optics-glass.md) | 背景模糊、半透明、细边框 | 音乐/视频、导航栏、悬浮层 |
| [4.2 液态玻璃](style-04-optics-glass.md) | 流体折射、动态光晕、形变 | 高端发布页、创新产品、概念展示 |
| [4.3 极光渐变](style-04-optics-glass.md) | 多色渐变网格、弥散光斑 | AI 产品、营销页、社交裂变 |

### 族 5 · 未来复古派
适用：有明确受众认同感的亚文化产品。

| 风格 | 特征 | 适用 |
|---|---|---|

## 口语 → 风格映射词典

用户几乎不会说风格名，只会说感受词。先把感受词翻译成族，再走决策树。**不要跳过这一步直接猜。**

### 高频口语映射

| 用户说 | 实际指向 | 直觉上容易错成 |
|---|---|---|
| 科技感 / 未来感 / 硬核 | **精密冷感**：1.3 暗黑优先 + 2.1 扁平，或 1.4 高密度 | ❌ 5.1 赛博朋克（霓虹+故障=土） |
| 别太土 / 高级感 / 有质感 | 低饱和 + 大留白 + 人文无衬线 + 克制用色；信息层级靠排版 | ❌ 大面积高饱和、渐变堆叠 |
| 商务 / 专业 / 权威 / 可信 | 1.1 或 1.4，中性偏冷，主色面积 ≤ 8% | ❌ 撞色、圆润黏土 |
| 年轻化 / 有活力 | 2.3 孟菲斯 或 3.2 黏土 或 5.3 Y2K | ❌ 赛博朋克（受众错位） |
| 温暖 / 亲和 / 治愈 | 3.4 有机自然 或 7.1 新中式；暖白底 + 柔和形状 | ❌ 纯白冷灰（显疏离） |
| 极简 / 干净 / 克制 | 1.1 瑞士极简 | ❌ 等同于「留白多」（极简是节奏，不是空白） |
| 简洁但不无聊 | 1.1 基底 + 1.2 的强字号对比，或局部 8.1 大字 | ❌ 全身极简（信息层级缺失） |
| 安静 / 专注 / 沉浸 | 1.3 暗黑优先，正文对比度高，减少强调色 | ❌ 多处次级色块干扰 |
| 怀旧 / 复古 | 7.2 复古印刷 或 5.3 Y2K | ❌ 泛黄滤镜（那是图像处理不是设计） |
| 国潮 / 东方 / 中国风 | 7.1 新中式 | ❌ 中日韩符号混搭 |
| 炫酷 / 冲击力 | 8.3 品牌动效 或 4.2 液态玻璃（限展示页） | ❌ 全站动效（效率型产品会崩） |
| 稳定 / 可靠 / 严谨 | 1.4 高密度 + 中性色 + 数字右对齐 | ❌ 强圆角与软阴影（暗示不可靠） |

### 「土」的来源诊断

用户说「土」，几乎总是这六个原因之一。直接对症下药，不要整体换风格：

1. **霓虹光晕过强** —— 阴影层数 > 3 层、模糊半径过大
2. **故障/扫描线常态触发** —— 动效一触发就出，做出廉价感
3. **渐变堆叠** —— 渐变叠渐变，界面发浑
4. **描边/阴影不统一** —— 各处随手调，风格一致性崩塌
5. **字体滥用** —— 装饰体做正文，或超过 3 个字族
6. **风格与场景错位** —— 用潮牌风格做严肃业务

前五项是执行问题，改执行即可，不必推翻风格。第六项才需要换族。

### 映射后仍要走决策树

口语只给方向，不给密度。确定候选族后仍需回答 Q1（密度）与 Q6（设备），否则会出现「选了科技感但密度是密的」这类矛盾组合。

查风格属性：

```bash
node scripts/catalog.js style "科技"    # 输出适用/禁用/性能/无障碍风险
```

## 选型决策树

按顺序回答，命中即停。

**Q1. 产品的核心任务是一次性浏览，还是反复操作？**
- 反复操作（工具、后台、终端）→ 密度「中/密」→ **族 1.4**，加族 2 或 3 做质感
- 一次性浏览（落地页、活动、内容）→ 密度「疏」→ **族 1.1 / 1.2 / 8.1**

**Q2. 用户是否需要界面有情绪/氛围？**
- 无，产品求稳求效率 → **族 1** 为主，族 2 辅助
- 有（消费、娱乐、社交）→ 进 Q3

**Q3. 情绪来自哪里？**
- 物理亲和感（软、圆、可摸）→ **族 3**（黏土/有机）
- 光学氛围（透、辉、悬浮）→ **族 4**
- 时代态度（潮、复古、实验）→ **族 5** 或 **族 6**
- 文化身份 → **族 7**
- 品牌自身符号 → **族 8**

**Q4. 有无明确的文化/地域/传统要求？**
- 有 → 族 7 直接定，不再往下选

**Q5. 是否需要暗色模式作为主形态？**
- 是（夜间使用、开发者、影音）→ **族 1.3** 作为基座叠在 Q3 的选择之上

**Q6. 目标设备与触屏/鼠标？**
- 触屏为主 → 圆角与热区放宽，倾向 2.2 / 3.2
- 鼠标密集操作 → 可用极小热区，倾向 1.4 / 5.2

## 混搭规则

- **同族可自由混**：1.3 暗黑优先 + 1.4 专业高密度；2.1 经典扁平 + 2.3 孟菲斯撞色
- **跨族最多 2 族**：族 2 + 族 4 是最稳的通用组合（扁平保证识别度，透明提供层级）
- **明确互斥组合**：
  - 族 1（无阴影网格）+ 族 3（阴影体积）→ 阴影会撕碎网格感
  - 族 1.1（极简克制）+ 族 6（粗野堆叠）→ 两者对"信息量"的判断完全相反
  - 族 5.1 赛博朋克 + 族 7.1 新中式 → 符号体系互斥
  - 族 3.3 写实拟物 + 族 4 透明 → 透明需要极简底色打底，拟物底色会让模糊失效

## 组合配方（可直接用）

| 场景 | 配方 |
|---|---|
| 通用 SaaS 后台 | 1.4 + 2.1 |
| 消费级 App | 2.2 + 3.4（Material You 圆润 + 有机暖色） |
| 教育/青少年 | 2.2 + 2.3（圆润容器 + 撞色活力） |
| 音乐/影音 | 1.3 + 4.1（暗黑基座 + 玻璃导航） |
| AI 产品 | 1.1 + 4.3（极简秩序 + 极光氛围） |
| 开发者工具 | 1.3 + 5.2（暗黑 + 终端质感） |
| 文创/市集 | 7.2 + 8.1（复古印刷 + 大字） |
| 政务/中老年友好 | 1.4 + 2.1（高密度 + 扁平大热区），不用族 3/4/5 |
| 品牌发布页 | 1.1 + 4.2 或 8.1 + 4.2 |
