# Token · 色彩

## on-* 强制配对结构

**任何颜色都必须成对声明：色值 + 它上面的文字色。** 单写一个 `#2563EB` 而不写「上面配什么字」是设计规格里的常见漏洞，因为色值是否可用取决于配对，脱离配对的色值没有意义。

```
primary       + on_primary        反色文字
secondary     + on_secondary
accent        + on_accent
destructive   + on_destructive
background    + foreground
card          + card_fg
muted         + muted_fg
```

### 成套配色目录

已备 14 套按产品类型组织的配色，全部 on-* 配对经 `scripts/contrast.js` 实测达标：

```bash
node scripts/catalog.js palette "校园"      # 取成套配色
node scripts/catalog.js verify             # 校验目录内全部 56 组配对
```

覆盖：通用SaaS、教育校园、政务适老化、内容资讯、电商零售、金融理财、医疗健康、活动营销、企业后台高密度、社交社区、开发工具、文创非遗、AI产品、影音媒体暗色。

换品牌色后**必须重跑 verify**，不能凭色相推断能否配白字。

## 中性色阶

一套 9–12 档，是整个界面的骨架。任何风格都不应绕过它自定义灰色。

### 角色映射（浅色）

| 角色 | 值 |
|---|---|
| 页面底色 | `--gray-50` |
| 卡片底色 | `--gray-0` |
| 抬升层底色 | `--gray-0` + `--shadow-2` |
| 边框/分割线 | `--gray-200` |
| 强分割线 | `--gray-300` |
| 文字一级 | `--gray-900` |
| 文字二级 | `--gray-500` |
| 文字三级（禁用/占位） | `--gray-400` |

**文字三级不承载信息**，只用于占位符与禁用态。

### 暗色模式（独立标定，不反相）

```
--gray-0:   #0F1115    页面底（最深）
--gray-25:  #141821
--gray-50:  #171A21    卡片
--gray-100: #1D212A
--gray-200: #262B36    抬升层
--gray-300: #333947    边框
--gray-400: #4B5262
--gray-500: #6B7280
--gray-600: #8B93A1
--gray-700: #AEB5C1    文字二级
--gray-800: #D3D8E0
--gray-900: #E6E8EC    文字一级（不用 #FFFFFF）
--gray-950: #F5F7FA
```

暗色模式核心规则：

- 正文**不用纯白**。纯白在暗底上产生光晕（halation），实际可读性反而下降。用 `--gray-900`（#E6E8EC）
- 层级靠**抬升**（更亮的底色），不靠更深的阴影
- 分隔线用 `--gray-300`，不用半透明白（半透明白在深色上会显灰）
- 品牌色在暗底上需提亮 10–20% 或降饱和，否则会"糊"

## 主色与强调色

```
--brand-50 … --brand-900    完整色阶
--brand-500                  默认主色
--accent                     强调色（与主色不同色相）
```

### 规则

- 主色 ≤ 2 个（同屏）
- 主色用于：主操作按钮、选中态、链接、关键数据高亮
- 强调色用于：次级高亮、品牌特写区域。**面积 ≤ 10%**
- 主色不与语义色同色相（绿色主色会让成功/危险状态混淆）
- 主色在页面上的面积占比 ≤ 8%（浅色模式）；深色模式可放宽

### 常见品牌色参考

`500` 档是**品牌色**（用于图标、强调线、选中边框），`按钮填充` 档是**唯一允许配白字**的色阶——两者不是同一个值。

| 色系 | 品牌色 500 | 按钮填充（白字达标，已实测） | 适用 |
|---|---|---|---|
| 蓝 | `#3B82F6` | `#2563EB` 5.17:1 | 通用 SaaS、科技 |
| 靛蓝 | `#4F46E5` | `#4F46E5` 6.29:1 | 工具、企业级 |
| 青 | `#0EA5E9` | `#0E7490` 5.36:1 | 通信、云服务 |
| 绿 | `#10B981` | `#047857` 5.48:1 | 环保、健康、增长 |
| 紫 | `#8B5CF6` | `#7C3AED` 5.70:1 | 创意、AI、开发者 |
| 玫红 | `#EC4899` | `#BE185D` 6.04:1 | 消费、活动 |
| 橙 | `#F97316` | `#C2410C` 5.18:1 | 电商、餐饮 |
| 红 | `#EF4444` | `#DC2626` 4.83:1 | 促销、活力（慎用为主色） |
| 高端/编辑 | 用 `--gray-900` 作主色 | — | 高端、杂志感 |

### 主按钮填充色的硬性规则

**主色 500 档几乎都配不了白字。** 实测：`#3B82F6` 3.68:1、`#10B981` 2.54:1、`#F97316` 2.80:1、`#8B5CF6` 4.23:1 —— 全部不达 4.5:1。

因此：

- 品牌色体系里必须单独定义一个 `brand-solid`（按钮填充色），取 600–700 档
- `brand-solid` 与 `brand-500` 可以是两个色值，这是正常的，不是错误
- 深色模式同理：暗底上浅色文字要配更亮的实色，且同样要跑脚本验证
- 上表数值全部由 `scripts/contrast.js` 实测得出，换品牌色时**必须重跑**，不能凭色相推断

## 语义色

```
--success   #10B981   成功、已完成、正常
--warning   #F59E0B   警告、需要注意、待处理
--danger    #EF4444   危险、错误、删除、不可逆
--info      #3B82F6   信息、提示、中性通知
```

### 规则（不可违反）

- 语义色**只表达语义**，不用于装饰与品牌
- 语义色**必须配文字或图标**，不单独用颜色表意（色觉障碍用户必需）
- 错误提示使用 danger + 感叹号图标 + 文字说明，三者同时出现
- danger 色不做大面积背景（整块红底会造成压迫感），用左侧色条 + 浅红底（`danger` 的 50 档）
- 语义色在暗色模式下需重新调校（提高明度，否则在深底上不够醒目）

### 浅色模式浅底配方

```
--success-bg: #ECFDF5   文案 #047857
--warning-bg: #FFFBEB   文案 #B45309
--danger-bg:  #FEF2F2   文案 #B91C1C
--info-bg:    #EFF6FF   文案 #1D4ED8
```

浅底 + 深文案才能在 4.5:1 上达标。常见错误是「浅红底 + 浅红字」。

## 渐变

```
--gradient-primary: linear-gradient(135deg, var(--brand-500), var(--brand-700))
```

- 渐变角度全局一致（默认 135°）
- 渐变只用于：品牌特写区、封面、图标底。不用于正文底、不用于语义提示、不用于大面积页面底
- 文字压在渐变上必须实测对比度；渐变最深端与最浅端都要测

## 风格调色覆写

| 风格 | 覆写要点 |
|---|---|
| 1.3 暗黑优先 | 重标定中性阶；强调色提亮 10–20%；禁用态用降不透明度 |
| 4.1 / 4.2 玻璃拟态 | 玻璃底色必须足够不透明（常需 0.5–0.7）才能承载 4.5:1 的文字；边框用半透明白 |
| 4.3 极光渐变 | 渐变只做背景层；内容层用不透明底色 |
| 2.2 Material You | 动态色仅作用于品牌色位；语义色固定不参与动态取色 |
| 5.1 赛博朋克 | 近黑底 + 高饱和霓虹；正文用近白而非霓虹色 |
| 6.1 粗野主义 | 原色直用（纯红纯黄纯蓝），不用色阶；黑底白字天然高对比 |
| 7.1 新中式 | 宣纸白 / 墨黑 / 朱红 / 黛青；朱红面积 ≤ 5% |
| 7.2 复古印刷 | 严格 2–4 专色；套印错位仅作用于装饰层 |
| 3.2 黏土风 | 马卡龙色系；文字用深色而非彩色 |
