# 反模式清单

出稿前对照一遍。每条都附了「为什么」和「改成什么」，因为反模式的危害通常不在于难看，而在于让用户做不了事。

## 布局

| 反模式 | 为什么坏 | 改成 |
|---|---|---|
| 固定像素宽度（`width: 500px`） | 在 360px 屏直接横向滚动，在 1920px 屏留大片空白 | `max-width` + `padding` + flex/grid |
| 12 个以上同级导航项 | 用户找不到目标，记不住位置 | 归组到 7 项以内 |
| 层级超过 3 层 | 用户在第 3 层已经不知道自己在哪 | 压缩层级，用筛选/标签替代嵌套 |
| 重要信息放在需滚动才能看到的位置 | 首屏是决定去留的地方 | 首屏放核心价值与主操作 |
| 卡片套卡片套卡片 | 三层边框三种底色，视觉噪声 | 减少嵌套层级 |
| 左右两栏 50/50 但内容量悬殊 | 视觉重心失衡 | 按内容量分配，或改为单栏 + 侧栏抽屉 |
| 用空白代替分组 | 用户无法判断两元素的关联 | 用间距/分割线/底色明确分组 |

## 色彩

| 反模式 | 为什么坏 | 改成 |
|---|---|---|
| 纯红纯绿表示状态 | 约 8% 男性红绿色盲无法区分 | 加图标或文字 |
| 用颜色做唯一选中态 | 色觉障碍用户看不出选中 | 加形状/字重/勾选标记 |
| 灰色文字对比度靠"看着挺清楚" | 肉眼判断对比度不可靠 | 取色器实测 ≥ 4.5:1 |
| 浅红底 + 浅红字 | 对比度通常只有 2:1 | 浅底 + 深文案（`danger-bg` + `danger-700`） |
| 一个界面 5 个强调色 | 全部失效，等于没有强调 | 主色 1 + 强调 1 + 语义色 |
| 渐变文字用在正文 | 渐变中段对比度必然不达标 | 渐变仅用于 ≥ 48px 标题 |
| 阴影用纯黑 | 在暖色界面上显脏 | 阴影色带品牌色相偏移 |
| 暗色模式直接反相 | 纯白字在 OLED 上产生光晕 | 独立标定暗色色阶 |

## 文字

| 反模式 | 为什么坏 | 改成 |
|---|---|---|
| 标签 = 控件值（placeholder 充当 label） | 用户输入后就失去字段含义 | 独立 `<label>` |
| 纯文字按钮无边界 | 用户不知道可点 | 文字按钮加下划线或图标 |
| 提示文案用浅灰 | 对比度不达标，且常被忽略 | 加深颜色 + 明确语气 |
| 长段落不分行 | 阅读行长超 40 汉字会串行 | 行宽限 680–760px |
| 错误提示「格式错误」 | 用户不知道错在哪、怎么改 | 「邮箱格式应为 xxx@xxx.com」 |
| 手写体/装饰字体做正文 | 小字号不可读 | 正文用印刷体 |
| 中文字体用 300 以下字重 | 笔画在屏幕上消失 | 正文 ≥ 400 |

## 交互

| 反模式 | 为什么坏 | 改成 |
|---|---|---|
| 破坏性操作只有一次点击 | 误删无法挽回 | 二次确认或可撤销 |
| 确认文案「确定吗？」 | 用户不知道会发生什么 | 「将永久删除 12 条记录，不可恢复」 |
| 无防重复提交 | 双击提交两次 | 提交后立即 loading + 禁用 |
| 用 hover 作为唯一信息渠道 | 触屏没有 hover | 触屏也可见，或点击触发 |
| 加载时整屏遮罩 | 挡住已加载内容 | 局部骨架屏 |
| 禁用按钮无原因说明 | 用户不知道自己能做什么 | tooltip 或帮助文案 |
| 提交失败清空表单 | 用户要重填 | 保留已填内容 |
| 弹层层层嵌套 | 说明信息架构有问题 | 压缩到 ≤ 2 层 |
| Toast 承载必须读的信息 | 会自动消失，用户错过 | 错误内联常驻 |
| 自动播放轮播无暂停 | 无法阅读，且强制消耗注意力 | 加暂停按钮 |

## 信息架构

| 反模式 | 为什么坏 | 改成 |
|---|---|---|
| 功能按内部组织架构命名 | 用户按心智模型找功能，不按部门找 | 按用户任务命名 |
| 同一概念两种叫法 | 用户以为是两件事 | 统一术语表 |
| 把主功能藏进二级菜单 | 核心功能应是主操作 |
| 首次进入无引导 | 新用户不知道能做什么 | 首次为空态做价值说明 + 创建入口 |
| 设置项全部平铺 | 超出 20 项后无法查找 | 分组 + 搜索 |

## 风格

| 反模式 | 为什么坏 | 改成 |
|---|---|---|
| 新拟态做长文本 | 同色底 + 灰字对比度必然不达标 | 正文区切回中性底色 |
| 玻璃拟态叠在纯色底上 | 失去质感，只剩半透明色块 | 玻璃下放渐变或光斑 |
| 赛博朋克做电商正文 | 霓虹底干扰商品图识别 | 风格限定在导航与装饰区 |
| 粗野主义用在后台表格 | 硬边框 + 位移反馈使密集信息不可读 | 密集区切回中性样式 |
| 大字排版用在功能界面 | 全站超大字导致不可用 | 大字只用于展示层 |
| 反设计用在错误提示 | 用户分不清是风格还是 bug | 错误提示保持中性 |
| 5 族风格混用 | 渲染逻辑互相冲突 | 跨族 ≤ 2 族 |
| 同一套图标库混 2px 和 1.5px 线宽 | 视觉重量不一致 | 全局统一线宽 |

## 动效

| 反模式 | 为什么坏 | 改成 |
|---|---|---|
| 动效 > 400ms 阻塞操作 | 用户感到卡，且注意力被拉走 | 缩短时长或改为可跳过 |
| 循环动效无停止条件 | 持续消耗注意力 | 加停止条件 |
| 缺 `prefers-reduced-motion` | 前庭功能障碍用户无法使用 | 实现降级 |
| 入场动画遮挡首屏内容 | 拖慢 LCP | 内容先出现，装饰后进 |
| 每个组件独立动效逻辑 | 破坏全局运动语言 | 统一缓动与时长表 |
| 装饰动画被误认为加载反馈 | 用户不知道系统在干什么 | 加载动效位置固定、形状统一 |

## 工程

| 反模式 | 为什么坏 | 改成 |
|---|---|---|
| 颜色/间距使用 token 表外的数值 | 暗色模式与主题切换失效 | 全部走 token |
| 阴影/圆角逐处手调 | 风格一致性崩塌 | 引用 token |
| 只做了暗色背景没做暗色色阶 | 层级与对比度崩 | 独立暗色 token 集 |
| `outline: none` 未替代 | 键盘用户不知道焦点在哪 | 自定义焦点环 |
| 图片无宽高/比例占位 | 加载后布局跳动 | 预留空间 |
| 骨架屏与真实内容结构不一致 | 内容出现时跳版 | 结构对齐 |
