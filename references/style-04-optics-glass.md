# 族 4 · 光学透明派

**核心逻辑**：让背景透过来，用模糊和光建立层级。
**气质**：轻盈、悬浮、氛围感强。
**密度**：疏 / 中。

## 共同宪法

### 必须

- 透明必须有"可读的底"——玻璃下方需要有足够对比的底色，模糊不能成为不透明性的借口
- 玻璃层有明确边界（1px 半透明亮边 + 背景模糊），否则和底色融为一体
- 全局光源一致，渐变位置与光晕方向固定
- 玻璃层上方的文字对比度必须实测，不能靠"看起来清楚"

### 禁止

- 半透明文字（对比度必然不达标）
- 玻璃层叠加玻璃层（模糊叠加会累积浑浊）
- 在信息密集区使用（透明背景下的密集信息会互相干扰）
- 高对比度背景照片上直接放玻璃文字（背景干扰无法靠模糊消除）

## 4.1 玻璃拟态 Glassmorphism

### 气质
半透明 + 背景模糊 + 细边框。Windows Vista Aero / Apple Big Sur 之后的延续。

### 机制

```
background: rgba(255, 255, 255, 0.15);   /* 或暗色 rgba(0,0,0,.25) */
backdrop-filter: blur(20px) saturate(180%);
border: 1px solid rgba(255, 255, 255, 0.25);
box-shadow: 0 8px 32px rgba(0, 0, 0, 0.12);
```

`saturate(180%)` 是关键——只有模糊没有饱和度提升，会得到"发灰的模糊"，而不是通透的玻璃。

### 构成要点

- 玻璃层分三种：背景玻璃（大面积、低不透明度）、卡片玻璃（中）、浮层玻璃（高 + 强阴影）
- 下方必须有**有色彩、有明暗变化的内容**（渐变、光斑、模糊的图像）。纯色背景下的玻璃=半透明色块，没有质感
- 细边框是玻璃感的关键，缺失后玻璃会"糊"
- 强调色透过玻璃时会被背景影响，需为玻璃上的强调元素单独调高对比

### 必须

- `backdrop-filter` 必须有降级方案（不支持时回退到高不透明度实色）
- 玻璃上的正文对比度 ≥ 4.5:1，靠**提高玻璃不透明度**来解决，不能降低标准
- 玻璃层数量单屏 ≤ 3 层
- 提供浅色/暗色两套玻璃参数（暗色下用低不透明度黑 + 亮边框）

### 禁止

- 在纯色背景上使用玻璃（失去质感，只剩半透明色块）
- 玻璃上的次要文字（低对比 + 低对比背景 = 双重失效）
- 玻璃卡片内再套玻璃卡片
- 与密集列表/表格混用
- 毛玻璃效果导致 GPU 开销失控（移动端注意 `backdrop-filter` 的性能代价）

### 翻车点

- **对比度崩塌**：这是玻璃拟态最常见的致命伤。浅色背景上 `rgba(255,255,255,.15)` + 灰字 = 对比度 1.8:1。必须实测，且通常需要把不透明度提到 0.5–0.7 才能达标
- 没有渐变/光斑背景，玻璃 = 半透明矩形
- 半透明叠加过多层，整屏发灰发浑，失去通透感
- 边框不一致（有的有有的没有），玻璃感立刻崩塌

## 4.2 液态玻璃 Liquid Glass / Aurora

### 气质
流体质感、动态折射、形变。比玻璃拟态更"活"，更强调运动。

### 构成要点

- **形变**：玻璃边缘随内容产生折射扭曲（SVG filter `feDisplacementMap` 或 WebGL）
- **动态光**：光斑缓慢流动，高光随指针或滚动移动
- **深度分层**：多层玻璃互相产生折射关系，形成空间纵深
- **响应式材质**：光标悬停时玻璃微微膨胀、边缘高光增强
- 强烈渐变底图（通常与主色同色相），玻璃作为统一材质贯穿全站
- 入场动效：元素从模糊到清晰的"显影"效果

### 必须

- 材质贯穿全局统一，不用时整体质感断裂
- 动效受 `prefers-reduced-motion` 约束（降级为静态渐变玻璃）
- 提供低性能降级路径（关闭形变与折射，保留静态玻璃）
- 玻璃上文字必须加独立底色或提高不透明度

### 禁止

- 在需要长时间阅读/填表的界面（动态形变持续吸引注意力，消耗认知资源）
- 在密集列表或表格上
- 与族 5/6 混用（三套强表现手法同屏会互相拆台）
- 依赖 WebGL 而无降级（部分环境不可用）

### 翻车点

- 性能：多层模糊 + 位移滤镜 + 动画同时运行，移动端帧率崩盘
- 形变过强导致文字边缘扭曲，牺牲可读性换视觉效果
- 只有装饰没有内容——大面积液态玻璃包裹的信息量很少
- 用户反馈「看不清」是最高频问题，通常出现在玻璃上的深色文字落在深色光斑上

## 4.3 极光渐变 Aurora / Gradient Mesh

### 气质
多色弥散光斑、柔和过渡、梦感。AI 产品与营销页的主流选择。

### 构成要点

- 3–5 个高饱和色团（品牌色系同色相 + 邻近色相），大面积弥散
- 模糊半径极大（`filter: blur(120px)`），完全看不出形状
- 网格布局承载彩色圆点，每点带 `mix-blend-mode`（screen / plus-lighter）
- 常作为背景层，上面覆盖纯色或高不透明度卡片保证可读性
- 缓动动画让色团缓慢漂移（周期 20–40s，不易察觉但避免静止感）

### 必须

- **渐变做背景，不做文字前景**。渐变上直接放彩色文字必然对比度不达标
- 内容层必须有不透明底色（卡片 `rgba(255,255,255,.9)` 或纯色），让文字落在稳定底上
- 渐变色与品牌色系一致，不能随机撞色
- 色团数量 ≤ 5，色相跨度 ≤ 120°（跨度过大变成彩虹，显得廉价）

### 禁止

- 渐变用于正文（对比度波动，且干扰阅读）
- 渐变用于错误/警告/危险提示（会削弱语义）
- 动画过快导致闪烁（色团漂移周期 ≥ 15s，位移幅度小）
- 在暗色模式用高饱和渐变（暗底上需要降饱和或加深底色）

### 翻车点

- 「AI 风」同质化：所有 AI 产品都用蓝紫渐变，产品失去辨识度
- 渐变叠加文字，颜色随色团漂移导致对比度忽高忽低
- 色团数量失控（7–8 个），变成彩虹尿布风
- 暗色模式下未重新调色，直接反相后色彩刺眼
