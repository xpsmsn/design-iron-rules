# 族 3 · 触感拟物派

**核心逻辑**：用阴影模拟真实体积，让界面"可摸"。
**气质**：柔和、亲和、有物理隐喻。
**密度**：疏 / 中。

## 共同宪法

### 必须

- 阴影是表达层级的**唯一主手段**，底色保持接近中性
- 光源方向全局统一（默认左上 45°），所有凸起凹陷遵循同方向
- 阴影颜色与底色同色相，不是纯黑
- 圆角较大，与柔和阴影匹配

### 禁止

- 多光源（互相矛盾的阴影方向会立刻破坏体积感）
- 高对比深阴影（族 3 的阴影是软的、浅的，不是族 1.4 那种浮起的深阴影）
- 在需要高密度信息处使用（阴影占空间、降低信息可读性）

## 3.1 新拟态 Neumorphism

### 气质
同色系凸起/凹陷。像一块被软雕刻出来的塑料面板。极简到有点冷。

### 机制

一块与背景**同色**的面，用两盏相反的"灯"雕刻：
- 凸起（外凸）：左上亮 + 右下暗
- 凹陷（内凹）：左上暗 + 右下亮

```
凸起：box-shadow: -6px -6px 12px #FFFFFF, 6px 6px 12px #D1D9E6;
凹陷：box-shadow: inset -4px -4px 8px #FFFFFF, inset 4px 4px 8px #D1D9E6;
```

### 构成要点

- 底色只能是**中间调**（#E0E5EC 一类），太亮或太暗阴影都失效
- 元素与背景**完全同色**，靠阴影区分
- 圆角 12–20px
- 强调色几乎不用，界面近乎单色；强调靠阴影强度差异表达
- 极简图标（线性、单色、几何）

### 必须

- 按下态必须切换为凹陷阴影——这是新拟态唯一的交互语言，不切换就失去了"可按"的暗示
- 焦点态必须可见（凹陷 + 强调色描边）
- 交互热区视觉尺寸与实际热区一致（新拟态最常见问题是"看起来是按钮但点不到"）

### 禁止

- 彩色元素（打破同色原则后阴影逻辑失效）
- 大面积文字内容（浅灰文字在浅灰底上极易不达标）
- 输入框用凹陷但不明显——用户认不出这是可输入的
- 与暗色模式混用（暗底上阴影完全失效，必须切回扁平）

### 翻车点

- **对比度灾难**：这是新拟态最大的结构缺陷。正文灰字在同色底上常常只有 2:1，远低于 4.5:1。缓解手段只有：底色推到更深或更浅、正文推到 #1A1A1A/ #4A5568、卡片底色用两级明度
- 用户认不出可点击性——凹陷/凸起在视觉上是装饰，缺少语义锚点
- 组件类型单一，整个界面一片"橡皮"
- 阴影值未全局复用，各处随手调，形成"多种新拟态"

## 3.2 黏土风 Claymorphism

### 气质
3D 黏土质感。比新拟态更圆润、更彩色、更轻松，儿童与教育产品常用。

### 构成要点

- **超大圆角**：卡片 24–32px，按钮 full，图标容器圆形
- 黏土质感三要素：
  1. 浅色柔光高光（内阴影，顶部偏亮）
  2. 同色相深色软阴影（外阴影，向下偏移大、模糊大）
  3. 微妙内边缘光（inset 1px 亮边）
- 阴影偏下方偏移（`0 8px 16px`），营造"物体放在桌上"
- 色彩可多彩 pastel（马卡龙色系），不局限同色
- 元素可轻微不规则、圆润厚实
- 插画风格与 UI 一致（都是黏土 3D），或 UI 极简 + 插画承担风格

### 必须

- 阴影参数全局统一（同一层级的黏土元素用同一组阴影值）
- 黏土材质不能压过信息——表格、密集列表、代码区改用扁平
- 高饱和色仅用于按钮与小面积元素
- 焦点态明确（描边或色块变化）

### 禁止

- 把正文放在黏土卡片上做长文阅读
- 黏土阴影 + 细边框 + 玻璃模糊叠加（三层材质互相打架）
- 严肃场景（金融、医疗、政务、司法）

### 翻车点

- 阴影太重变成"塑料玩具感"，与信息型产品不匹配
- 色彩过于糖果化，中文文字在小字号下与糖果底色冲突严重
- 所有元素都黏土化，包括表格和代码块——风格过度覆盖内容

## 3.3 写实拟物 Skeuomorphism

### 气质
真实材质与光影。iOS 拟物、录音机、相机应用的质感。

### 构成要点

- 真实纹理：木纹、金属拉丝、纸张、皮革、石纹（用高质量纹理贴图，不是噪点）
- 全局统一光源，所有材质的光影方向一致
- 物理正确的边缘：倒角高光、材质厚度、投影
- 精细程度极高：这是族 3 中唯一需要美术资源的风格
- 控件隐喻直接：旋钮对应旋转、推子对应滑动、拨盘对应档位

### 必须

- 光源、透视、材质、细节四者全部一致——任何一项不统一就会"假"
- 拟物只用于**高频核心控件**，其余界面保持简洁
- 提供退化的纯色模式（材质加载失败 / 低端设备 / 省电模式）
- 纹理资源做懒加载，纹理总大小控制在首屏 500KB 内

### 禁止

- 拟物图标配扁平文字排版（材质语言断层）
- 用拟物隐喻承载无法理解的复杂功能（"这个旋钮到底是调什么？"）
- 在纹理上直接放小字号文字（纹理干扰阅读）
- 把整屏做成拟物——信息密度会被材质吞掉

### 翻车点

- 只学纹理不学光影，材质贴上去但立体感不成立
- 性能崩溃：全屏高分辨率纹理 + 实时阴影，低端设备卡顿
- 年代感陷阱：写实拟物在当代语境里自带 2010 年代记忆，可能与"专业/现代"的品牌调性冲突
- 精细度不够时最尴尬——半拟物比纯扁平更难看。要么做到位，要么退回扁平

## 3.4 有机自然 Organic / Biophilic

### 气质
自然形态、暖色调、柔和肌理。健康、环保、农业、生活方式类产品。

### 构成要点

- **色组**：暖白 `#FAF7F2`、鼠尾草绿 `#87A96B`、陶土 `#C97B5A`、砂 `#E8DCC8`、深棕 `#3E3A34`
- **形状语言**：不对称有机曲线、叶片形、云形、手绘边缘、不规则圆角（`border-radius: 60% 40% 55% 45%`）
- 材质：纸纤维、亚麻、木质、水彩晕染
- 插画：手绘植物、动物、抽象自然形态
- 排版：衬线或人文无衬线（Source Han Serif / 思源宋体）
- 动效：缓慢、有弹性、自然生长感（时长可到 500–800ms，但仍不阻塞操作）

### 必须

- 有机形状用在装饰与容器，交互控件仍用规则形状（不规则热区影响点击准确性）
- 暖色底上的文字对比度重新核算（暖白底比纯白底更容易达标，但深绿/深棕文字需实测）
- 动效保留 `prefers-reduced-motion` 降级
- 纹理强度控制在不影响正文对比的范围内（纹理叠加不超过 4% 不透明度）

### 禁止

- 有机形状用于输入框、复选框等需要精确对齐的小控件
- 饱和度过高的绿色（容易撞上"环保"以外的其他语义）
- 纹理压在正文区（哪怕是 4% 叠加，长文阅读也会疲劳）
- 与族 5 未来复古混用（时间感完全不同）

### 翻车点

- 「自然」做成「土」——棕色 + 颗粒纹理 + 手写体三件套过度使用，界面显旧
- 绿色用得太泛，产品调性无法与其他竞品区分
- 有机形状导致栅格失效，界面失去秩序感，反而更难用
- 手写字体用于正文，中文手写体在小字号下几乎不可读（只能用于 ≥ 24px 的标题）
