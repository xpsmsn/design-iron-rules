# 族 7 · 文化地域派

**核心逻辑**：调用传统材质与纹样。
**气质**：文化识别度、叙事性、有根。
**密度**：疏 / 中。

## 共同宪法

### 必须

- 传统元素经过**当代转译**，不做文物复刻（直接贴二方连续纹样会显得廉价）
- 文化元素集中在容器、装饰、标题区，不侵占功能区
- 材质纹理不透明度受控，保证正文对比度
- 有明确的来源认知——用户能看出是哪个文化体系，而不是泛东方

### 禁止

- 文化符号的随意混搭（中日韩混用会显得不懂）
- 传统元素出现在错误语境（宗教符号用于商业促销、丧葬纹样用于喜庆场景）
- 把文化做成"皮肤"——只有纹样没有排版逻辑和空间节奏的东方拼贴
- 纹样密度过高影响信息识别

## 7.1 新中式 / 东方极简

### 气质
留白、格栅、朱红、书法感。当代国潮、文化机构、茶与器物。

### 构成要点

- **色组**：宣纸白 `#F5F1E8`、墨黑 `#1C1A17`、朱红 `#C8322D`、黛青 `#3E5C5B`、赭石 `#A8763E`
- **空间**：大面积留白，元素疏排，负空间是主角（留白占比可达 60%）
- **格栅**：木质格栅、云纹、雷纹作为分隔元素，而不是满屏底纹
- **字体**：标题用宋体/楷体（思源宋体 / 霞鹜文楷），正文用黑体（思源黑体）——**不混用两种衬线**
- **形状**：方正为主，圆角克制，偶见圆窗、月洞门
- **线条**：细横线分隔，模拟宣纸边界
- **印章**：作为点缀，出现在角落或落款位，不做大面积装饰

### 必须

- 正文用黑体而非宋体（宋体小字号在屏幕上笔画会粘连）
- 朱红只用于强调点与印章，面积 ≤ 5%
- 留白是有节奏的留白，不是随便散落（元素仍需落在隐性网格上）
- 印章不承载关键信息，只是文化点缀

### 禁止

- 宣纸纹 + 大红 + 毛笔字 + 云纹 四件套全上（典型的"国潮糊弄"组合）
- 用书法字体做正文
- 格栅作为可点击热区的边界（实际热区应大于视觉）
- 把"东方"等同于日式和风（和风、藏式、伊斯兰式是完全不同的体系，不可混用）

### 翻车点

- **符号堆砌**：纹样、印章、毛笔、灯笼、青花，全都用一遍 = 廉价国潮
- 留白不足：疏朗是核心气质，元素一多就变成普通中式风网页
- 中文字体在小字号下的可读性（宋体 12px 在屏幕上几乎糊成一片）
- 场景错配：严肃的法律条文、学术出版用国潮纹样会削弱权威感

## 7.2 复古印刷 Risograph / 活字

### 气质
套色印刷错位、网点、粗纸、独立刊物气质。

### 构成要点

- **印刷工艺特征**：
  - 半调网点（halftone）纹理
  - 套印错位（overprint misalignment），色彩边缘轻微偏移 2–4px
  - 有限色板（2–4 色），模拟专色印刷
  - 纸边毛糙、轻微噪点
- **色组**：红 + 蓝（经典双色 Risograph）、或黑 + 荧光橙
- **字体**：粗衬线或粗无衬线标题，标题可做半调处理
- **版面**：报纸/杂志式网格，粗分割线，图注用小号字
- **插画**：几何形状与线描，非写实

### 必须

- 错位量全局统一（不能有的偏移 2px 有的 6px）
- 套色只在装饰层与插图层，不用于正文（正文出现套印重影会严重影响阅读）
- 正文用单色清晰渲染
- 纸纹不透明度 ≤ 5%

### 禁止

- 正文使用任何印刷伪影效果
- 色板超过 4 色
- 把噪点当作"质感"大量添加（噪点是印刷特征，不是滤镜）
- 与极简主义直接冲突（印刷质感需要内容与结构做载体）

### 翻车点

- 伪影过度：正文也带重影，整个界面发糊
- 纸纹 + 噪点 + 网点三种纹理叠加，纹理噪点互相污染
- 印刷特征做成滤镜（用噪声贴图）而非真正的设计语言（色板限制 + 套印逻辑）
- 小字号正文用网点效果，不可读

## 7.3 纸感手作 Craft / Paper

### 气质
撕边、胶带、手写、纸纹、手作温度。礼物、节日、社区、手账。

### 构成要点

- **材质**：纸纹背景、卡片有轻微投影（模拟纸片浮在桌面上）、边角可撕边/圆角不规则
- **胶带**：半透明 washi 胶带作为装饰（页面标题、照片角部）
- **手写**：手写体用于标题与批注（仅 ≥ 24px），正文仍用印刷体
- **颜色**：低饱和暖色（米 `#FBF7EF`、浅木 `#D9C4A3`、墨绿 `#6B8E6B`、砖红 `#C96A5B`）
- **贴纸**：少量圆点/星星贴纸作为点缀
- **拼贴**：照片、票根、明信片元素错落排布
- **阴影**：柔和的纸质投影 `0 3px 8px rgba(0,0,0,.08)`，不是浮起的强阴影

### 必须

- 手写体只用于标题与批注，绝不用于正文与表单
- 撕边/不规则边界的可点击区域实际热区大于视觉
- 纸纹不透明度 ≤ 6%，且不压在正文区
- 装饰密度受限，核心信息区保持干净

### 禁止

- 手写体用于按钮文案（影响可识别性与专业感）
- 装饰元素挡住内容或热区
- 纸纹 + 阴影 + 撕边三个效果同时作用于同一元素（效果叠加会显脏）
- 装饰密度超过信息密度（会变成贺卡而非界面）

### 翻车点

- 「手作」做成「幼稚」：装饰过度、颜色过粉、信息区被包围
- 手写字体是装饰性中文字体，小字号下笔画糊连
- 撕边效果让界面边界模糊，误触率高
- 与移动端手势冲突：撕边边缘的点击判定不稳定
