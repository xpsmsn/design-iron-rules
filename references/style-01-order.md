# 族 1 · 秩序理性派

**核心逻辑**：网格与排版驱动一切，装饰为零。
**气质**：克制、可信、专业、高信息密度。
**密度**：1.1/1.2 疏 → 1.4 密。

## 共同宪法

### 必须

- 一切靠对齐与留白建立层级，不靠色块、阴影、边框
- 栅格 12 列，所有元素落在列线上；故意不对齐的元素每屏不超过 1 处
- 字号层级跨度明显：正文与标题字号比 ≥ 1.4
- 留白 ≥ 组件本身高度的节奏感（疏密度下留白通常是内容宽度的 1/3 以上）
- 图标功能单一，一个图标区不超过 8 项

### 禁止

- 阴影（族 1 内不混族 3 阴影）
- 渐变
- 圆角超过 4px（1.3/1.4 允许 0–4px；1.1/1.2 允许到 8px）
- 装饰性插图占据信息区
- 一个视图内字号档位 > 6

## 1.1 瑞士极简 Swiss / International

### 气质
网格严谨、大留白、去装饰。像美术馆目录或学术出版物。

### 构成要点

- 无衬线为主（Neue Haas Grotesk / Helvetica / Inter / 思源黑体）
- 严格左对齐，不用居中排版（居中只用于单栏极简落地页）
- 大量非对称留白，元素故意偏置
- 字号跳跃：正文 16px + 标题 64px 混排，靠对比而非装饰
- 颜色面积：白 90% + 黑 8% + 强调色 ≤ 2%
- 无分隔线，靠间距分组

### 配色

```
背景    #FFFFFF / #FAFAFA
文字    #111111 一级 / #555555 二级 / #888888 三级
强调    单一品牌色，面积占比 ≤ 2%
```

### 适用 / 不适用

✅ 作品集、SaaS 落地页、品牌官网、设计工作室
❌ 信息密集后台、需要区分卡片的功能型界面（留白不够用）

### 翻车点

- 「极简」做成「空」——留白大但没有节奏，缺对齐基准
- 为了极简删掉必要的状态提示，导致用户不知道发生了什么
- 强调色面积超 2%，立刻失去极简感

## 1.2 编辑杂志 Editorial

### 气质
出版物气质，强对比排版，衬线与无衬线混排，适合有阅读量的内容。

### 构成要点

- 衬线大标题（Playfair / 思源宋体 / 思源宋体 Heavy）+ 无衬线正文
- 字号跳跃极夸张：标题 96px + 正文 17px
- 多栏网格（2–3 栏），栏间距明显大于行距
- 首字下沉、悬挂标点、栏宽严格控制在 680–760px
- 图片满栏或出血，文字块严格贴网格
- 上下大横线分隔章节，替代卡片

### 配色

```
背景    #FFFFFF 或 #F7F5F2（微暖纸感）
文字    #1A1A1A / 正文 #333333
强调    1–2 色（常为红/深蓝/墨绿），用于章节标题与链接
```

### 适用 / 不适用

✅ 内容站、专题页、学术出版、长文阅读
❌ 表单密集的界面、需要频繁扫视比较数据的页面（多栏会拖慢扫视）

### 翻车点

- 多栏用在中短内容上，单栏内容被拉成两条细长条，阅读行长过短
- 衬线体用于正文（中文尤甚），小字号下可读性断崖下跌
- 图文比失衡，图片数量撑不起编辑感

## 1.3 暗黑优先 Dark-First

### 气质
深色基底，高对比，发光强调色。既是功能选择，也是氛围选择。

### 关键认知

**暗色不是把亮色反相。** 直接反相会导致纯白文字在 OLED 上产生光晕（halation），反而降低可读性。

### 构成要点

- 中性色阶重新标定，不复用亮色值：
  ```
  背景    #0F1115  最深（大面积）
  抬升层  #171A21  卡片
  再抬升  #1F232C  弹层
  边框    #2A2F3A
  文字一级 #E6E8EC  （不用 #FFFFFF）
  文字二级 #A0A6B2
  文字三级 #6B7280
  ```
- 用**抬升**代替阴影：暗色下没有「更深的阴影」，靠更亮的底色表达层级
- 强调色提高饱和度与明度以抵消暗背景削弱（同一色在暗底上需提亮 10–20%）
- 阴影保留但只用于真正浮起的元素，且改用黑色 `rgba(0,0,0,.5)` 强化而非柔化
- 图片与视频需加轻微内描边，避免与背景融在一起

### 必须

- 正文对比度仍 ≥ 4.5:1（暗底更易达标，但浅灰文字极易不达标，需实测）
- 禁用态用降低不透明度实现，不靠降低到看不清
- 提供浅色模式时，两套色阶独立设计而非机械反转

### 禁止

- 纯黑 `#000000` 大面积背景 + 纯白文字的极端组合
- 在暗底上使用饱和度低于 50% 的强调色（会"糊"进背景）
- 暗底上使用大面积浅灰卡片（会形成刺眼亮块）

### 翻车点

- 直接把亮色模式 `filter: invert()` 一改了事
- 阴影在暗底上失效，导致浮层边界不清——必须改用边框或抬升底色
- 图片素材原本为亮底，插入暗色界面后显得刺眼，未做边框或背景融合

## 1.4 专业高密度 Pro-Dense

### 气质
交易终端、监控台、后台管理的信息密度。信息量本身就是价值。

### 关键认知

密度高 ≠ 拥挤。**高密度是"单位面积内更高的信息密度"，前提是每个元素仍有明确的视觉分组。** 无分组的高密度才是真拥挤。

### 构成要点

- 行高压缩到 1.4–1.5，行高小于 1.4 时表格会"糊"成一片
- 正文字号可降到 13–14px（密度中）、14px（密度高）
- 紧凑间距序列 `4 · 6 · 8 · 12 · 16`，不再用 20/24
- 表格为核心组件，右侧固定操作列，首列固定
- 多栏布局（左侧导航 + 中间内容 + 右侧属性面板）
- 状态用**极窄色条**（3px 左侧条）表达，密集排列下色块会互相干扰
- 数字全部**右对齐 + 等宽数字**（tabular-nums），便于纵向比对

### 必须

- 热区可降到 24×24，但相邻间距 ≥ 8px
- 提供密度切换开关（紧凑/标准），用户自己选
- 表格必须提供：列宽拖拽、列排序、列显隐、批量操作、选中计数
- 分页优先于无限滚动（密集列表需要回到某条记录）

### 禁止

- 用彩色背景块标记状态（密集下变成色块墙）
- 大圆角、大阴影（吃掉本就紧张的垂直空间）
- 图标代替文字标签（密集下扫视效率低，文字反而更省空间）
- 关键操作隐藏在 hover 才出现的菜单里（密集界面几乎不用 hover）

### 翻车点

- 只压行高不做视觉分组，结果是一坨可读但不可用的信息
- 没有列排序，在 50 行以上的数据里无法定位
- 数字不右对齐，导致个位/十位错位，比对全靠肉眼
- 移动端强行套用桌面高密度，触控目标全部超小
