# 族 5 · 未来复古派

**核心逻辑**：调用一个明确的时代符号系统。
**气质**：态度鲜明、圈层认同、亚文化。
**密度**：疏 / 中。

## 共同宪法

### 必须

- 符号系统完整——选一个时代符号就把该符号用透（网格 + 字体 + 色彩 + 纹理四者同源）
- **正文可读性不妥协**：风格只作用于标题、装饰、背景，正文与数据区保持中性
- 时代感来自风格本身，不依赖具体某个 IP 或品牌素材（避免侵权与过时）
- 提供「低强度模式」开关——同一套设计可以在正式场合收敛为中性配色

### 禁止

- 符号混搭（霓虹 + 扫描线 + 故障 + 像素 四者同屏 = 风格噪声）
- 风格元素压在数据区与正文上
- 严肃、高频、效率导向的正式业务界面
- 用风格遮蔽不可读性问题

## 5.1 赛博朋克 Cyberpunk

### 气质
霓虹、湿冷都市、反乌托邦。暗底 + 高饱和霓虹 + 故障反馈。

### 构成要点

- **色彩**：近黑底 `#0A0E14` / `#05070A`，霓虹青 `#00F0FF`、霓虹粉 `#FF2E88`、警示黄 `#F5FF00`、酸绿 `#39FF14`
- **字体**：标题用宽体/压缩体无衬线（Orbitron / Chakra Petch / 思源黑 Heavy），数据区用等宽
- **网格**：背景常带透视网格地平线（synthwave grid）、扫描线（scanlines）、CRT 暗角
- **发光**：霓虹光晕 `text-shadow / box-shadow` 多层叠加，模拟霓虹管
- **斜切**：按钮与卡片常切 45° 角，呼应义体/机械感
- **故障**：hover 时 RGB 通道分离位移、水平撕裂
- **边框**：细发光边框 + 角标装饰（切角、六边形）

### 必须

- 霓虹色用于**强调与状态**，正文用近白 `#E8EDF2` 保证对比度
- 发光效果不叠加到正文（光晕会降低文字锐度）
- 故障动效触发在 hover/错误反馈上，不做常态循环
- 扫描线与暗角不透明度 ≤ 8%（超过 8% 会造成可读性下降与视觉疲劳）

### 禁止

- 霓虹色作为大面积背景（紫粉大底会引发视觉疲劳与不适）
- 在暗色背景下用中等饱和度的霓虹（会"糊"进背景，失去发光感）
- 与族 7 文化地域混用
- 用在医疗、金融、教育、政务等严肃场景
- 在商品图/头像上叠加故障滤镜（破坏内容可信度）

### 翻车点

- 「科技感」做成「廉价感」——霓虹光晕过强、故障效果频繁触发，反而像劣质游戏
- 正文可读性崩坏：很多赛博朋克页面中正文实际对比度 < 3:1
- 暗底 + 高饱和叠加导致长时间使用眼疲劳
- 与业务调性冲突：教育产品用赛博朋克会让学生觉得"不严肃"

## 5.2 终端 TUI

### 气质
命令行界面。等宽字、单色或双色、字符装饰。开发者工具的天然语言。

### 构成要点

- **字体**：全站等宽（JetBrains Mono / Cascadia Code / Fira Code），字号 13–14px
- **色彩**：经典绿 `#00FF00` + 黑底，或琥珀 `#FFB000` + 深棕底，或现代派（低饱和青灰 + 高亮强调）
- **边框**：ASCII 字符绘制（`┌─┐│└┘`）或 1px 实线模拟终端窗框
- **布局**：严格单列纵向流，天然适配窄屏
- **提示符**：`$`、`>`、`#` 作为前缀，路径与参数用不同颜色区分
- **装饰**：扫描线、光标闪烁、启动日志输出
- 键盘优先：所有操作有快捷键，焦点通过 outline 而非背景色表达

### 必须

- **对比度优先于单色美学**。经典纯绿 `#00FF00` 在黑底上对比度很高但过于刺眼，实际产品建议降到 `#00C853` 一类柔和绿
- 交互控件（按钮、输入框、复选框）仍需符合铁律 2 的热区要求——不能因为"终端就该小"
- 光标闪烁等动效响应 `prefers-reduced-motion`
- 提供复制友好：所有可复制内容（命令、路径、ID）用等宽 + 一键复制

### 禁止

- 用终端风格承载长篇中文正文（等宽字体的中文段落非常难读）
- 终端风格用在非技术受众产品上
- 用颜色作为唯一的信息区分手段（等宽终端尤其容易出现"好看但看不懂"）
- 把不可用能力伪装成终端命令（视觉暗示能力，实际没有）

### 翻车点

- 中文字符宽度导致对齐崩溃（中文全角占 2 字符，ASCII 表格边框会错位）
- 「装酷」——风格强于功能，界面为了终端感牺牲了信息组织
- 复制粘贴时带入终端装饰符号（框线和提示符），实际使用受阻
- 长时间阅读舒适性差：等宽字体 + 单一色彩缺乏视觉锚点，眼睛容易疲劳

## 5.3 Y2K 千禧 / Vaporwave

### 气质
金属质感、气泡按钮、闪光、复古未来（2000 年代互联网审美）。

### 构成要点

- **材质**：金属渐变（银/金/铬）、玻璃质感（早期 CD 光盘反光）、塑料光泽
- **色彩**：粉紫渐变 `#FF6EC7` → `#7B5CFF`、薄荷绿 `#B8FFE0`、银白、铬黑
- **形状**：胶囊/气泡按钮、超大圆角、椭圆与星形装饰
- **字体**：圆体、泡泡字（可通过粗体 + 圆角处理）、渐变填充文字、描边文字
- **元素**：星号 sparkle、闪光点、像素爱心、CD 反光盘、蝴蝶、无限符号
- **背景**：渐变天空、星空、网格地平线（与 synthwave 有交集）

### 必须

- 渐变文字仅用于超大标题（≥ 48px），小字号渐变文字必然模糊
- 正文与数据区保持中性高对比
- 装饰元素不覆盖交互热区
- 色彩复杂度控制在 4 色以内

### 禁止

- 与族 6 粗野主义混用（一个柔软一个硬，边角逻辑冲突）
- 小字号使用描边文字或渐变文字
- 在需要可信度的场景（金融、教育、政务）使用
- 装饰密度超过信息密度的 2 倍

### 翻车点

- 时代感过强导致产品显得不专业（尤其是金融、教育类受众）
- 金属渐变在低亮度屏幕上会变成脏灰色
- 装饰元素（星号、爱心）过多显得幼稚，与目标用户年龄错配
- 无障碍问题：粉色/紫色在暗底上的对比度经常不达标
