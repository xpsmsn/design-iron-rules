# 族 2 · 扁平几何派

**核心逻辑**：纯色块 + 几何形状表达层级。
**气质**：清晰、轻快、易实现、跨平台兼容最好。
**密度**：中。

## 共同宪法

### 必须

- 层级靠底色明度差与色块，不靠阴影
- 强调色面积受控（单屏 ≤ 10%），用于主操作与关键状态
- 圆角统一，同层级组件一致
- 图标扁平化，与字体同一视觉重量

### 禁止

- 渐变（2.3 孟菲斯除外，该风格以撞色为特征）
- 拟物纹理、木纹、金属
- 双重描边（外描边 + 内阴影）
- 超过 2 种强调色同屏

## 2.1 经典扁平 Flat

### 气质
Linear / Notion 早期那一派。干净、无修饰、内容为王。

### 构成要点

- 底色为主（白 / 浅灰 #F7F8FA / 近黑），卡片纯白
- 层级：卡片靠 1px 边框 `#E5E7EB` + 极弱阴影 `0 1px 2px rgba(0,0,0,.04)`
- 强调色单色，最常见蓝 `#3B82F6` 或品牌色
- 按钮实心主色，次级为灰底或纯文字按钮
- 图标 1.5px 线宽（与 Inter 匹配）
- 输入框：1px 边框 + 聚焦时边框变主色，不用高亮光晕

### 配色

```
页面底   #F7F8FA
卡片底   #FFFFFF
边框     #E5E7EB
文字     #111827 / #6B7280
主色     #3B82F6（可换品牌色）
成功     #10B981   警告 #F59E0B   危险 #EF4444
```

### 适用 / 不适用

✅ 通用 SaaS、后台、表单、工具、报表
❌ 需要氛围感或情绪表达的消费级产品（会显得冷淡）

### 翻车点

- 扁平做到底后层级消失——全靠留白和边框，卡片之间分不清。需要靠边框或底色差补回来
- 强调色用得太浅（如 `#60A5FA`）在白底上按钮文字对比度不达标
- 用灰色区分层级但灰度差 < 10%，肉眼不可见

## 2.2 Material You 动态取色

### 气质
Android 13+ 的 Material 3。圆润、柔和、色彩随内容变化。

### 核心机制

**动态取色**：从壁纸/用户选定的种子色生成整套色板，同一色相下自动派生容器色、强调色、状态色。用户看到的不是"设计师选的蓝"，而是"系统给我的蓝"。

### 构成要点

- 容器替代卡片：不同层级用容器色深浅表达（surface / surface-container-low / -high / -highest），不是靠阴影
- **大量圆角**：按钮全圆（full），卡片 16–28px，输入框 4–28px
- 极浅阴影或无阴影 + 色调偏移描边（outline 用主色的低透明度版本，不是纯灰）
- 强调色用在关键节点与 FAB，次要信息用容器色
- 图标偏饱满（Material Symbols 风格）
- 交互反馈：点击时容器色变深（state layers，透明度叠加），不用缩放或阴影

### 必须

- 动态色必须保留**品牌底线色**（错误/警告等语义色不能用动态色覆盖，否则危险提示可能变绿）
- 提供关闭动态色、回落到品牌色的选项
- 触控热区符合 Material 规范的 48dp

### 禁止

- 在暗色模式下继续用亮色模式的容器色阶
- 圆角过大导致"一切都是胶囊"（正文段落也用全圆角会毁掉可读性）
- 动态色与品牌标识冲突时，用动态色

### 翻车点

- 动态取色后主色恰好落在业务色域（如外卖产品主色变蓝，与品牌绿冲突）
- 容器色阶设计不足，模式之间层级丢失
- 中文界面套用 Material 全圆角，文本框变成胶囊，违和

## 2.3 孟菲斯撞色 Memphis / Y2K

### 气质
高饱和撞色、手绘几何、80/90 年代 Memphis 运动设计 + 千禧辣妹科技。

### 构成要点

- **色组**：一组 4–6 个高饱和色同屏出现（粉 `#FF4D8D`、黄 `#FFD23F`、青 `#00D9C0`、紫 `#8B5CF6`、橙 `#FF7A00`、黑）
- **形状库**：圆、三角、波浪线、方块、螺旋、气泡；随机分布但对齐到网格
- **粗描边**：3–6px 黑色描边包裹形状
- **字体**：超大无衬线标题（Cooper Black / 粗几何体），或手写体点缀
- **纹理**：半调网点（halftone）、斜条纹、噪点
- **阴影**：硬阴影 `4px 4px 0 #000`，无模糊
- **圆角**：混合使用，刻意不一致

### 必须

- 撞色成组使用，不随机取色——先定一个色板再铺
- 黑描边宽度全局统一
- 硬阴影偏移量全局统一
- **正文字号不小于 15px**，正文区域从简（装饰集中在标题区与插图区）
- 装饰元素不得与可交互元素形状相同（否则用户会点装饰）

### 禁止

- 装饰元素占据可点击区域
- 撞色用在表单的错误提示区（会削弱危险信号的严肃性）
- 正文区使用纹理背景
- 与族 4 透明混用（半透明 + 撞色会互相削弱）

### 翻车点

- 「活泼」做成「吵」——装饰密度压过信息密度，用户找不到内容
- 撞色在正文长文下严重影响阅读
- 风格正确但与场景不符：用在政务、医疗、金融、严肃教育场景会引发不适
- 描边不统一（有的 3px 有的 5px），硬阴影会瞬间失去风格一致性
