# 组件铁律检查表

按组件类型逐项过。每项不满足即返工。

## 全局（每个组件都要查）

- [ ] 间距、字号、圆角、阴影、动效全部取自 token，规格内无表外数值
- [ ] 5 态完整（加载 / 空 / 错误 / 成功 / 无权限）——不适用也要显式确认
- [ ] 暗色模式有独立色阶，不是反相
- [ ] 键盘可达 + 焦点态可见
- [ ] 对比度达标（正文 4.5:1，组件 3:1）
- [ ] 热区达标（44×44，或族 1.4 的 24×24 + 8px 间距）
- [ ] 边界情况已处理（超长文本、0 值、大数值、空集合）
- [ ] 360 / 768 / 1280 / 1920 四档成立

## 按钮

- [ ] 主 / 次 / 幽灵 / 危险四级样式明确，同屏只有一个主按钮
- [ ] 文案是动词短语，不是名词（「提交申请」不是「提交」按钮写「申请提交」）
- [ ] 加载态：点击后立即 loading + 禁用，防重复提交
- [ ] 禁用态：不只是变灰，要说明为什么（tooltip 或帮助文案）
- [ ] 破坏性按钮用 danger 样式 + 二次确认或可撤销
- [ ] 图标按钮有 `aria-label`
- [ ] 点击热区 ≥ 44px，视觉尺寸可小于热区（用 padding 扩展）

## 输入框

- [ ] 有可见 `<label>`，不只靠 placeholder
- [ ] 聚焦态明显（边框变色 + 光晕，二者至少其一）
- [ ] 校验时机：失焦校验格式，提交校验全部
- [ ] 错误提示在字段下方，指名道姓说明怎么改
- [ ] 支持粘贴、自动填充、中文输入法组合态
- [ ] 类型正确（`type="email"` `type="tel"` `inputmode="numeric"`）
- [ ] 不禁用复制粘贴（密码类除外且需说明）

## 表单

- [ ] 分组用 fieldset + legend
- [ ] 必填标记明确（文字 + 属性，不只靠颜色）
- [ ] 提交失败保留所有已填内容
- [ ] 标签位置一致（全在上 / 全在左，不混用）
- [ ] 有自动保存或草稿机制（长表单）
- [ ] 字段数量合理（> 15 个字段考虑分步）

## 列表 / 表格

- [ ] 提供排序（> 20 项时必须）
- [ ] 提供筛选（> 50 项时必须）
- [ ] 数字右对齐 + `tabular-nums`
- [ ] 空态区分「首次为空 / 筛选为空 / 搜索为空」
- [ ] 批量操作有选中计数与确认
- [ ] 行高不小于 1.4（否则视觉粘连）
- [ ] 长列表虚拟滚动或分页，不用无限滚动（无法回到某条记录）
- [ ] 操作列固定（桌面端）

## 导航

- [ ] 当前位置有明确指示（不只靠颜色）
- [ ] 层级深度 ≤ 3 层
- [ ] 一级导航项 ≤ 7 个
- [ ] 有返回路径，不是单向门
- [ ] 吸顶导航处理下方内容滚上来的可读性
- [ ] 移动端有汉堡菜单或底部导航
- [ ] 面包屑用于深层页面

## 弹层 / 抽屉 / 弹窗

- [ ] Esc 可关闭（模态必须）
- [ ] 打开时焦点移入，关闭时焦点返回
- [ ] 点击遮罩可关闭（非模态任务窗除外）
- [ ] 不嵌套弹层（超过两层说明信息架构有问题）
- [ ] 标题明确说明这是什么
- [ ] 危险操作在弹层中不默认获得焦点
- [ ] 移动端从底部弹出，不占满全屏

## Toast / 通知

- [ ] 可撤销的操作优先用 Toast + 撤销
- [ ] 不承载必须阅读的信息（会自动消失）
- [ ] 不堆叠超过 3 条
- [ ] 不遮挡主要内容与操作按钮
- [ ] 时长 4–10s，暂停在悬停时

## 卡片

- [ ] 内间距一致（全局同一 `--space-*`）
- [ ] 内层圆角 = 外层圆角 − 内边距
- [ ] 整卡可点击时，内部不放其他可点击元素（或明确声明触发区）
- [ ] 卡片高度一致或对齐方式明确
- [ ] 卡片信息层级清晰：标题 → 关键信息 → 次要信息 → 操作

## 图标

- [ ] 同一层级用同一套图标库
- [ ] 线宽统一（全局 1.5px 或 2px）
- [ ] 图标尺寸随字号（12/16/20/24/32）
- [ ] 图标有 `aria-label`，不单独承载语义
- [ ] 不混用线面两种风格

## 表格专项（族 1.4 必查）

- [ ] 列宽可拖拽
- [ ] 列可排序（表头有方向指示）
- [ ] 列可显隐
- [ ] 首列/操作列冻结
- [ ] 数字列右对齐
- [ ] 空值显示为「—」而非空白
- [ ] 表头固定，滚动时保持可见
- [ ] 横向滚动有视觉提示

## 图表专项

- [ ] 不只靠颜色区分系列（配线型、标记点或直接标注）
- [ ] 有数据标签或悬停数值
- [ ] 有坐标轴单位
- [ ] 网格线对比度 ≥ 3:1 或明显弱化（不能是"看不见但也不消失"）
- [ ] 颜色对色觉障碍友好（避免红绿直接对比）
- [ ] 图表类型与数据关系匹配（不要用饼图表示时间序列）
